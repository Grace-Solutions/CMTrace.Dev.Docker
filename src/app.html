About CMTrace Web

CMTrace Web is a fast, modern, 100% client-side reimplementation of the classic CMTrace log viewer for SCCM / ConfigMgr logs. It runs entirely in your browser — no server, no uploads — and works directly from a local file:// path or any static host.

Features

  • Reads CMTrace, legacy SCCM/ConfigMgr and plain-text log formats.
  • Virtual scrolling for smooth viewing of 100k–1M+ lines.
  • Live filtering by text, severity, component, thread and time range.
  • Find with regex & case options, plus persistent highlight rules.
  • Built-in Win32 / HRESULT error-code lookup.
  • Merge multiple logs, live tail (follow), and export to log/CSV.
  • Light & dark themes, command palette, keyboard-first workflow.
